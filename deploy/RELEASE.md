# v0.35.0 作業自由填寫與共用表單修正

- 作業登錄保留科目、登錄日期與對象，下方合併為一個可換行的內容框，每次儲存一筆作業。
- 新作業預設截止日為登錄日期、繳交方式為學生自行勾選；進階設定保留在編輯頁，舊作業資料不變。
- 修正共用彈窗內容缺少內距，以及深色標題／關閉按鈕沿用反白配色而看不見的問題。
- 統一表單欄位間距、控制項寬度與手機版邊界；彈窗開啟時鎖定背景捲動，保留鍵盤關閉功能。
- 瀏覽器檢查涵蓋作業、紀錄、成績、帳號、活動、個人資料、信箱、登入服務與聊天，以及 13 種主題及手機寬度。
- 本版只有前端變更，不需更新 API 或 Cloudflare Worker；固定入口不變。

完整歷史請見 [更新紀錄](../log.md)。
