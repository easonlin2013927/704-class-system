# v0.27.0

本版加入全站離線保護。裝置失去網際網路時，登入頁與所有系統頁面會立即切換成離線提示並停止操作；系統會自動檢查連線，網路恢復後回到原本畫面。PWA 應用程式外殼已加入安全快取，完全離線重新開啟時仍能顯示提示，但不會把公告或帳號資料存入瀏覽器。

專案同時移除兩份已被新版文件取代、未被引用的舊稽核紀錄。此版本只有靜態前端與 PWA Service Worker 變更，API 程式與資料庫結構不需更新。

# v0.26.1

本版一次修正 v0.25 系列稽核發現的問題：自訂權限會真正控制前端功能與後端資料範圍，最大權限學生可使用被授權的管理功能；帳號安全中心可在帳號管理中查看及撤銷工作階段；個人化可設定常用功能；通知新增活動、成績、聊天、檢舉及全員通知分類；全站搜尋新增學生紀錄、檢舉與聊天訊息，並依帳號權限限制結果。

一般學生仍只會看到自己的作業、成績與紀錄；權限提升不會改變帳號身分，也不會繞過 API 授權。正式 API 容器使用 `announcement704/704-api:0.26.1`，維持 `/data/704-class-system/uploads:/data/chat-files` 掛載。

# v0.25.0

PWA 安裝頁與 704 班級徽章重新設計，並同步更新 192／512 圖示與前端快取版本。完成權限細分、全站搜尋、公告草稿／排程／閱讀狀態、作業提交、成績加權統計、電子郵件摘要、帳號安全中心、聊天封鎖與訊息編輯。API 升級時會自動建立必要資料表與欄位，原有資料不會刪除。
