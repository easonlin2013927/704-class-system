# v0.31.0 登入服務綁定

- 設定的帳號管理加入登入服務，可主動連接及解除 Google，並顯示官方品牌標誌。
- 第一次必須帳密登入；登入不再以學校或已驗證信箱自動對應。
- 綁定與解除需確認系統密碼，綁定需最近五分鐘的 Google 授權證明。
- 每個外部帳戶只能對應一個系統帳號；資料庫限制重複綁定，不自動覆蓋原綁定。
- 解除透過外鍵撤銷該綁定的登入工作階段，保留帳密登入；不修改通知信箱。
- 本版需更新前端、Worker 與 API。API 升級會使舊的 Google 工作階段失效，使用者需帳密登入後綁定；不會自動把信箱轉成綁定。
