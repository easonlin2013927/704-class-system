# v0.38.0 班級工具獨立授權

- 「段考英雄榜編輯與公布」、「班級留言板管理」與「班級留言板回覆」改成三項獨立權限。
- 教師在「學生帳號 → 班級工具權限」選擇學生或小老師並逐項授權；只能調整這三項，無法變更其他權限或管理員／教師帳號。
- 管理員在既有「帳號管理 → 編輯 → 功能權限」設定。儲存後使用者重新整理即可更新操作介面，API 每次請求檢查最新權限。
- 英雄榜編輯權限包含公布、取消公布與讀取未公布設定；留言板管理只授予刪除他人便條，不允許移動他人的便條，回覆權限單獨控制。
- 包含真實 PostgreSQL 權限、越權、撤銷與功能檢查，以及教師授權／學生操作的瀏覽器檢查。需手動更新 API，Worker 不需更新。

完整歷史請見 [更新紀錄](../log.md)。
