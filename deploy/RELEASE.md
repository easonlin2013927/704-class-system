# v0.25.1

管理員網站設定新增「全站外部通知」總開關。關閉後系統只保留收件閘通知，裝置推播、即時通知郵件、摘要郵件、週五排行榜郵件及等待中的外部通知均不再送出；電子郵件驗證流程不受影響。此版也附上 v0.25.0 權限、帳號安全中心、常用功能及搜尋範圍的稽核報告。

正式 API 容器使用 `announcement704/704-api:0.25.1`，維持 `/data/704-class-system/uploads:/data/chat-files` 掛載。

# v0.25.0

PWA 安裝頁與 704 班級徽章重新設計，並同步更新 192／512 圖示與前端快取版本。完成權限細分、全站搜尋、公告草稿／排程／閱讀狀態、作業提交、成績加權統計、電子郵件摘要、帳號安全中心、聊天封鎖與訊息編輯。API 升級時會自動建立必要資料表與欄位，原有資料不會刪除。

正式 API 容器需使用 `announcement704/704-api:0.25.0`，並維持 `/data/704-class-system/uploads:/data/chat-files` 掛載。
