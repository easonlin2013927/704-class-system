# v0.34.1 記住我啟動流程修正

- 進入系統時先確認既有登入狀態，不先顯示可輸入的帳密表單；有效登入直接進入已登入介面。
- 連線失敗或查詢逾時顯示重試與手動登入選項，不將連線問題直接當作未登入。
- 切換入口、登出及登入失效時取消舊恢復流程，避免較晚的回應覆蓋目前畫面或輸入內容。
- 公告等資料較早失敗時，仍等待權限確認回呼完成，避免再次短暫跳回登入表單。
- 不在瀏覽器新增儲存密碼、登入憑證或個人資料；保留後端登入驗證及原有記住我期限。
- 本版只有前端與檢查變更，不需更新 API 或 Worker。重新整理網站或重新開啟 PWA 即可載入新版。

完整歷史請見 [更新紀錄](../log.md)。
