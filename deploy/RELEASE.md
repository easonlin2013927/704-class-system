# v0.36.0 班級互動、資料繳收與聊天升級

- 新增全班公開心情留言板。學生可留言，教師、小老師及管理員可回覆；新增可逐帳號授權的留言板回覆權限。
- 新增段考英雄榜入口，明確標示尚未完成、暫不開放，不公開任何成績。
- 新增資料繳收項目、截止日、全班批次已繳交／未繳交／排除，以及一鍵未繳交提醒。教師及管理員預設可管理，其他帳號可個別授權。
- 提醒只排入未繳且有驗證信箱的學生，回報跳過原因；同項目同學生 10 分鐘內不重複提醒，寄送前再次確認繳交狀態。
- 移除收件閘入口並停用其查閱 API；舊通知資料仍保留給郵件、推播、摘要及備份使用。
- 聊天新增在線／暫離／離線、未讀數與已讀姓名。可手動選擇狀態，停止心跳約 2 分鐘後視為離線；在線時閒置 5 分鐘視為暫離。
- 聊天管理人員可檢視實際附件名稱並下載，保留成員／權限驗證與三天到期限制。
- 訊息及附件完成後約 1 分鐘準備離線提醒，含寄送者、內容摘要與檔名；已讀、在線、收回、離開群組、關閉通知時不寄送。附件不直接附加於郵件。
- 需同步更新 API 與 Cloudflare Worker，固定 PWA 入口不變。資料庫為可重複執行的新增遷移，不刪除既有使用者資料。

完整歷史請見 [更新紀錄](../log.md)。
