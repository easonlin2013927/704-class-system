# v0.33.3 今天功能修正與文件整理

- 修正「今天」查詢不存在的公告與活動欄位，以及教師／管理員紀錄查詢的參數數量錯誤。
- 集中顯示今日已發布且未過期的公告、今日活動、今日登錄或未來三天截止的作業、待補交紀錄及未讀通知。
- 日期統一依臺北時區；作業日期以純日期傳輸，避免時區造成截止日偏移。
- 作業與紀錄遵守帳號權限；一般學生只讀取指派給自己的作業與個人紀錄。載入失敗可按「重新載入」。
- README 改為專案介紹、固定入口及使用方式；完整更新紀錄移到根目錄 log.md，並提供相鄰導覽連結。
- 本版需更新 Pages 與 API，Worker 路由無須變更；資料庫結構不變。

完整歷史請見 [更新紀錄](../log.md)。
