# v0.37.0 軟木留言牆與段考頒獎台

- 班級留言板改為全螢幕軟木牆，僅保留返回及新增便利貼的主操作。以本地 SVG／CSS 製作木框、軟木與紙張，不依賴外部圖片。
- 登入成員可新增便利貼。作者可拖動或使用方向鍵調整位置，靠近邊緣自動捲動，位置保存在伺服器。教師及管理員亦不能移動他人便條。
- 點開便利貼可閱讀完整文字與公開回覆，沿用回覆及內容管理權限；離開頁面會清理更新計時器與尺寸監聽。
- 段考英雄榜可由教師與管理員設定名稱、1／3／5 名及每名學生，學生與小老師僅能查看。
- 頒獎台顯示即時姓名、暱稱及頭像，以黑白線條及金銀銅點綴；手機支援橫向查看五名模式。
- 新增位置及英雄榜資料表遷移，保留原有留言及其他班級資料；驗證作者限制、座標、名次唯一性、角色、SQL 與桌面／手機操作。
- 前端需配合 API v0.37.0；API 依使用者要求手動執行 deploy/update-api.sh，Cloudflare Worker 路由相容，不需更新。

完整歷史請見 [更新紀錄](../log.md)。
