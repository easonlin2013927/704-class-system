# v0.25.0 功能稽核報告（2026-11-07）

本報告以原始碼路由、角色判斷、前端導覽與自動化檢查交叉核對。下列問題是 v0.25.0 的原始稽核結果，已於 v0.26.1 全部修正；保留此表作為版本追蹤紀錄。

## v0.25.0 已確認、v0.26.1 已修正的問題

|嚴重度|功能|問題|影響|
|-|-|-|-|
|高|細分權限|學生即使被勾選全部權限，前端仍依 `student` 角色固定顯示學生功能；後端多個操作也直接要求教師或管理員角色。|重新登入後介面不會增加教師／管理功能，這不是快取問題。|
|高|細分權限|權限中介層對所有 GET 請求直接放行，部分讀取端點仍只依角色檢查。|關閉某項權限可能只隱藏介面或阻止寫入，不能完整阻止資料讀取。|
|中|帳號安全中心|工作階段管理元件建立在「個人化／通知」頁的渲染流程中，但「帳號管理」會改走另一個頁面。|使用者目前無法從帳號管理頁看到或撤銷其他登入裝置。|
|中|常用功能|後端已有 `preferences` 儲存介面，但前端沒有選擇、排序或套用常用功能的畫面。|「功能不要全部同時顯示」只有「更多功能」收合，尚未完成個人化常用功能。|
|中|通知偏好|個人通知設定只有公告、作業、積分、評語；活動、成績、聊天等通知會走預設允許。|使用者無法逐類關閉所有已存在的通知種類。|
|低|全站搜尋|搜尋結果可找到公告、作業、成績；帳號只供管理員搜尋，尚未涵蓋聊天、學生紀錄與檢舉。|名稱為「全站搜尋」，但資料來源尚不完整。|

## 程式檢查已通過

* JavaScript／Node.js 語法檢查。
* 靜態網站建置。
* 密碼雜湊測試。
* Cloudflare Worker 路由、跨來源、錯誤轉送、大檔串流測試。
* 聊天附件、公告附件、頭像與桌布的程式上限均為 400 MB；聊天附件保留三天並由排程清除。

## 尚需人工情境測試

* 草稿、排程發布與到期隱藏的實際時間點。
* 公告已讀統計在多位學生帳號下的結果。
* 作業繳交、教師查看繳交與成績權重的實際資料結果。
* 每日／每週摘要信與週五排行榜信的定時寄送。
* 400 MB 檔案在各裝置、校網及 Cloudflare 路徑的完整上傳。
* 聊天封鎖、訊息編輯及檔案三天到期的跨帳號行為。
