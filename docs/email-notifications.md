# 電子郵件通知設定

電子郵件通知需要伺服器設定 Gmail SMTP。學生預設信箱以登入帳號加上 `@stu.kcislk.ntpc.edu.tw` 產生，唯一的教師預設信箱為 `kensun@kcislk.ntpc.edu.tw`；這些由管理員設定的預設信箱鎖定且可直接接收。若登入帳號含 `@` 或其他無法組成有效信箱的字元，不會自動產生，須由管理員處理。

學生及教師可在「設定 → 帳號管理」新增、變更或刪除自行新增的信箱，新增與變更需輸入有效期 5 分鐘的驗證碼。管理員可變更預設信箱，或要求人員下次登入時新增或變更指定信箱並完成驗證。

管理員請使用已啟用兩步驟驗證的寄件帳號，建立 Gmail 應用程式密碼，並將伺服器環境變數 `MAIL_GMAIL_USER` 與 `MAIL_GMAIL_APP_PASSWORD` 設定於受保護的部署環境；勿將密碼放入程式碼、GitHub 或對話中。部署前須依 `server/package.json` 安裝相依套件。變更 Google 帳號密碼可能會撤銷應用程式密碼。

系統將新通知加入資料庫佇列。自行新增的信箱通過驗證後才寄送；暫時失敗或觸及寄件限制時會延後重試。Gmail 接受寄件並不保證信件進入收件匣。驗證信可能因寄件額度或網路問題延遲，驗證碼到期時需要重新申請。管理員可在網站設定發送測試郵件，依信箱查看狀態並匯出 Excel。

公告、作業、加扣分、評語及檢舉通知由伺服器產生並排隊；管理員的全員通知亦會寄往啟用帳號可用的信箱。電子郵件通知不能由個人關閉；設定中的通知種類選項控制裝置推播。
