# 電子郵件通知設定

電子郵件通知需要伺服器設定 Gmail SMTP，且每個使用者自行驗證收信信箱。登入帳號不一定是信箱；系統不會將未驗證的帳號名稱當成收件地址。學生及教師可在「設定 → 通知」輸入收信信箱並驗證。

管理員請使用已啟用兩步驟驗證的寄件帳號，建立 Gmail 應用程式密碼，並將伺服器環境變數 `MAIL_GMAIL_USER` 與 `MAIL_GMAIL_APP_PASSWORD` 設定於受保護的部署環境；勿將密碼放入程式碼、GitHub 或對話中。部署前須依 `server/package.json` 安裝相依套件。變更 Google 帳號密碼可能會撤銷應用程式密碼。

系統將新通知加入資料庫佇列。信箱通過驗證後才寄送；暫時失敗或觸及寄件限制時會延後重試。Gmail 接受寄件並不保證信件進入收件匣。驗證信可能因寄件額度或網路問題延遲，驗證碼到期時需要重新申請。

公告、作業、加扣分、評語及檢舉通知由伺服器產生並排隊；管理員的全員通知亦會寄往啟用帳號已驗證的信箱。電子郵件通知不能由個人關閉；設定中的通知種類選項控制裝置推播。沒有驗證信箱的帳號不能收到信件，請各使用者完成驗證。
