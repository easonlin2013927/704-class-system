# 管理員使用手冊

## 批量管理（v0.28.0）

帳號管理可全選目前篩選結果或全班學生，再批次啟用、停用、要求更換密碼或要求新增電子郵件。作業、學生紀錄、成績與聊天發言權限也提供批量動作。

## 系統健康與備份中心

維護人員可從頁首開啟「健康與備份」，查看 API、PostgreSQL、記憶體、資料庫大小、通知開關與 1.8 TB 資料碟可用空間。按「立即建立備份」會將壓縮備份寫入掛載資料碟，完成後可下載或刪除。

備份與正式資料若位於同一顆硬碟，無法防範硬碟本身故障；請定期下載備份到另一台電腦或其他儲存裝置。下載的備份含帳號與班級資料，必須妥善保管，不可公開分享。
# 帳號列表操作按鈕（v0.31.1）

帳號列表的編輯及刪除按鈕採用一致尺寸。手機版會將操作區放在人員資料與狀態下方，勾選框仍可用於批量操作。
# 郵件測試原因（v0.33.2）

匯出 Excel 會重新讀取測試狀態。請同時查看「詳細原因」、「建議處理方式」和「目前全站外部通知」；原因依每筆任務、目前設定及實際錯誤代碼產生。

已取消的任務不會重試。若原因是「當時通知關閉」，即使現在已開啟，舊任務仍是已取消，需重新按「發送測試郵件」。系統不會自動重送歷史通知。

綠色表示寄件服務已接受，紅色表示寄送錯誤，黃色表示等待處理、驗證或額度，灰色表示取消、停用或未納入等。寄件服務接受不代表已進入收件匣；若未收到，請檢查垃圾信與收件單位政策。

「失敗次數」只計失敗，不是總寄送次數；「最近失敗時間」只對新版記錄提供。舊資料只有 550 等單一代碼時，無法還原完整服務回應，請更新 API 後重新測試。已下載的檔案不會隨系統更新，請重新匯出。

錯誤代碼參考：[Gmail SMTP 說明](https://support.google.com/mail/answer/3726730)、[Nodemailer 錯誤欄位](https://nodemailer.com/errors)。
