# 704公告系統使用中心

## 離線畫面（v0.27.0）

系統偵測到裝置沒有網際網路時，會自動顯示「目前沒有網際網路」畫面，並暫停原頁面的操作。系統會持續檢查連線；重新連上 Wi-Fi、行動網路或有線網路後，會自動回到斷線前的畫面，不需要重新登入。

離線期間不能閱讀尚未載入的資料，也不能新增、修改或送出內容。系統不會將公告或使用者資料改存到瀏覽器。

## 班級生活功能（v0.14.0）

- [學生操作手冊](Student-Life.md)：作業勾選、私人提醒與聊天，僅包含學生操作。
- [教師與管理員操作手冊](Classroom-Management.md)：科目、作業、缺交、評語、聊天管理及學校網路連線排解。

學生首頁會顯示自己的待補交及評語提醒。作業及活動資料保存於雲端帳號。

- [個人化設定](Personalization.md)：7 種風格、頭像、暱稱與跨裝置保存。
- 公告支援可選擇開啟的評論區，留言顯示頭像與原名稱（暱稱）。

## 各系統登入網址

| 身分 | 登入網址 |
| --- | --- |
| 學生 | [學生登入／安裝 PWA](https://easonlin2013927.github.io/704-class-system/student/) |
| 教師與小老師 | [教師端登入／安裝 PWA](https://easonlin2013927.github.io/704-class-system/teacher/) |
| 維護人員（管理員） | [維護人員登入](https://easonlin2013927.github.io/704-class-system/admin/) |

這三個是永久入口，網址不含版本號，系統更新後也不需要更換書籤或重新取得連結。

請使用符合帳號角色的入口。三個畫面獨立，切換網址不會取得不同角色權限。

請依照自己的身分選擇手冊：

- [學生使用手冊](Student-Guide.md)：登入、尋找公告、閱讀重點與排除問題。
- [教師使用手冊](Teacher-Guide.md)：撰寫、格式設定、發布、置頂、修改與刪除。
- [管理員設定](Administrator-Setup.md)：資料庫、帳號權限、部署與維護。
- [維護人員使用說明](Maintenance-Guide.md)：維護入口、服務狀態及設定。
- [管理員使用手冊](Admin-Guide.md)：批量管理、系統健康與 1.8 TB 資料碟備份。
- 管理員具有教師公告管理功能，並可管理帳號與全站跑馬公告；詳見[維護人員使用說明](Maintenance-Guide.md)。

公告由雲端資料庫集中儲存，不會因學生清除瀏覽器資料或更換手機而消失。沒有到期自動刪除功能；教師刪除或管理員維護資料庫才會移除。這是保留政策，不代表資料庫服務永不故障；管理員仍須備份。

API 與資料庫已完成連接。請使用管理員配發的帳號登入，沒有帳號時請先聯絡管理員。
# v0.25.0 新功能

新版提供全站搜尋、公告草稿／排程／閱讀狀態、作業線上繳交、加權成績摘要、每日或每週郵件摘要、登入裝置管理，以及學生聊天封鎖。較少使用的功能收進「更多功能」，讓手機與平板導覽保持簡潔。
