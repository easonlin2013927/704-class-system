# 維護人員使用說明

## 班級生活管理（v0.14.0）

新增科目管理、作業簿、個別學生紀錄、及聊天管理。管理員可建立及啟停科目、管理作業與學生提醒，並停用學生聊天或處理被檢舉訊息。操作與權限請閱讀[班級管理手冊](Classroom-Management.md)。

「設定」分為個人化、網站設定；個人化可選 7 種風格、上傳頭像、設定暱稱，網站設定保留狀態表、標語與跑馬公告。管理員可切換任一公告的評論區並刪除評論。詳見[個人化設定](Personalization.md)。

[前往維護人員永久入口](https://easonlin2013927.github.io/704-class-system/admin/)

請使用維護人員獨立入口，輸入 role 為 admin 的帳號。教師或學生帳號不能登入此入口。

管理員擁有教師的全部公告權限：可新增、編輯、置頂與刪除公告，也能設定登入標語。管理員另有「帳號管理」，可以建立學生、教師與其他管理員、調整帳號角色及刪除帳號。至少須保留一名管理員，且不能刪除目前登入帳號。

「設定」內另有全站跑馬公告。啟用後會顯示於登入頁及登入後頁面的頂端；停用會保留已寫內容。請勿在公開跑馬文字中放置密碼或學生個資。

帳號可在管理員登入後由「帳號管理」建立；初始密碼不限制長度，可留空，建立後請安全地交付給帳號本人。管理員仍可用主機端 `server/account.mjs` 緊急建立或重設管理員帳號，JSON 的 role 填 admin，切勿把密碼提交至 GitHub。資料庫結構會在新 API 啟動時自動升級，不會清空公告。

重新整理需再次登入；登出或切換入口清除記憶體憑證。角色變更及密碼重設可在帳號名單的編輯視窗操作。資料庫權限、備份及緊急復原請依 deploy/README.md 使用主機工具。

登入入口不符會被後端拒絕。刪除帳號會一併撤銷其登入工作階段。若服務失效，先檢查 api704 容器日誌、PostgreSQL 狀態與 Tunnel；不要藉由公開資料庫埠修復。

管理員在「設定」頁查看表格形式的系統狀態。「帳號管理」先呈現人員名單，按「建立人員」才開啟填寫視窗。上方屋子圖示可從設定及帳號管理返回公告首頁。

## 編輯帳號與登入選項

在名單按「編輯」可修改登入帳號、姓名、狀態，管理員亦可更換角色。勾選「重設密碼」才會替換原密碼，未勾選時即使欄位留空也不會清空密碼。「登入時要求更換密碼」會讓使用者登入後先更換密碼，完成前不能使用一般功能；「停用帳戶」阻止登入。編輯後既有登入會失效。教師僅能編輯學生；自己不能停用自己，至少保留一位啟用中的管理員。
