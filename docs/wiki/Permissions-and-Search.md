# 權限、常用功能與搜尋

## 細項權限

管理員可在「帳號管理 → 編輯 → 權限」逐項授予發布公告、作業、成績、學生紀錄、檢舉、加扣分、科目、帳號、全員通知、聊天管理及網站設定權限。權限會同時控制導覽選項、操作按鈕及 API 資料範圍。

學生帳號即使取得管理權限，身分仍是學生，因此仍可使用學生聊天、檢舉中心與自己的作業功能；獲授權的管理功能會額外出現在導覽列。未取得管理權限的學生只能讀取自己的作業、成績與學生紀錄。

## 常用功能

在「設定 → 個人化 → 常用功能」最多選擇 8 項。儲存後，所選功能會直接顯示在主導覽列，其他可用功能收納在「更多功能」。只會顯示帳號有權使用的項目。

## 全站搜尋

全站搜尋可搜尋公告、作業、成績、學生紀錄、檢舉、聊天訊息及帳號。搜尋結果仍遵循權限：一般學生只會搜尋到自己的資料與自己參與的聊天；具有管理權限的帳號才可搜尋相應的全班資料。

## 通知分類

在「設定 → 通知」可分別管理公告、活動、作業、成績、評語與提醒、聊天、檢舉進度及全員通知。關閉某分類只會停止該分類的裝置推播與通知郵件，系統內收件閘仍會保留通知。

## 帳號安全中心

在「設定 → 帳號管理 → 帳號安全中心」可查看目前與其他登入工作階段。若看到不認識的裝置，可按「登出此裝置」撤銷該工作階段。
