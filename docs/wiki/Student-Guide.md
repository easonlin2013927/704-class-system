# 學生使用手冊

## 作業、提醒與聊天（v0.14.0）

上方功能列已新增作業簿、我的提醒及聊天。作業勾選只保存自己的完成檢查，缺交與個別評語只會顯示自己的紀錄。完整步驟與常見問題請閱讀[學生班級生活手冊](Student-Life.md)。

學生登入後，頁首標示為「班級公告」，方便辨識目前所在的學生公告頁面。

「設定 → 個人化」可選擇 7 種風格、上傳頭像、設定暱稱，儲存後會跟隨帳號保留。顯示名稱為「原名稱（暱稱）」。公告開啟評論區時可留言；自己的評論可點「刪除評論」再確認刪除。評論為一般文字，頭像與暱稱會一起顯示。

首頁公告區的活動倒數會顯示活動日期與剩餘天、時、分、秒，每秒更新；到期後顯示「活動已開始」。重新登入可載入最新活動。學生只會看到對象為「學生」或「全部人員」的公告。

[前往學生永久登入／安裝入口](https://easonlin2013927.github.io/704-class-system/student/)

這份手冊只說明學生閱讀公告的操作。請向班級管理員取得正式網站網址及個人帳號。

## 第一次登入

1. 使用手機、平板或電腦開啟網站。
2. 使用 README 中的「學生登入」獨立連結，頁面顯示「學生登入」。
3. 輸入教師或管理員提供的帳號與密碼，按「登入系統」。
4. 登入後會看到公告列表。閱讀完成後，在共用電腦按右上角「登出」。

沒有自行註冊或網站內重設密碼功能。忘記密碼、沒有帳號或選錯身分時，請聯絡班級管理員。不要將密碼交給同學。

## 找到需要的公告

首頁預設顯示全部公告。置頂公告優先顯示，其餘依發布日期排序。左側或上方的分類可選擇重要通知、課務資訊、活動消息及一般公告。

搜尋框可搜尋標題、內文及發布者。若沒有結果，先清空搜尋框並切回「全部公告」。搜尋和分類會同時生效。

公告卡片顯示分類、日期、標題、摘要、發布者與公告對象。點選標題或卡片可閱讀全文；摘要可能省略內容，日期、集合地點及攜帶物品請以全文為準。

## 閱讀全文

螢光筆通常用來強調期限；粗體、底線及清單協助整理重點。外部連結會在新分頁開啟，請確認連結來源可信再輸入資料。

按「返回公告列表」可回首頁。公告對象是說明標籤，目前所有已授權帳號皆可閱讀全部公告，並非私密分班資料夾。

## 更新與保存

公告集中存放於雲端。換手機、清除快取、關閉瀏覽器都不會刪除公告。系統沒有公告到期自動移除機制。

列表不會即時推播更新。需要最新內容時可重新登入；重新整理頁面會清除暫存登入狀態，需再次輸入帳密。系統不把登入憑證或公告寫入瀏覽器本機儲存。

網站目前沒有已讀紀錄、收藏、離線閱讀、附件下載或通知提醒。請自行確認是否完成閱讀。

## 常見問題

### 顯示尚未設定雲端服務
網站管理員尚未完成資料庫連接，請等待通知。更換密碼或重複登入無法解決。

### 登入失敗
確認電子郵件、密碼、大小寫及所選身分。若仍失敗，請管理員確認帳號已啟用且具有學生角色。不要把密碼貼到 Issues。

### 電子郵件與桌布

進入「設定 → 帳號管理」可查看學校預設信箱；預設信箱鎖定，若有錯誤請聯絡管理員。按「新增電子郵件」，輸入地址後寄送驗證碼，再於驗證畫面輸入 6 位數代碼；代碼有效 5 分鐘。自行新增的信箱可以變更或刪除，變更後需重新驗證。

管理員可能要求下次登入時新增或變更指定信箱，請依畫面操作並完成驗證。若驗證信延遲或驗證碼過期，可以重新申請。電子郵件通知固定啟用，裝置推播可在「設定 → 通知」選擇。全站桌布可在「設定 → 個人化」設定。

指定給你的公告、作業、缺交紀錄、評語及教師新增的成績，以及新活動，會排入電子郵件通知。加扣分不發送即時通知。若離開系統期間收到聊天訊息，也會收到提醒；同一人 30 分鐘內的離線聊天提醒會合併。每週五台灣時間晚上 8 點系統會排入班級排行榜郵件，實際收到時間可能受寄件額度影響。

### 網頁空白或一直載入
確認網路可用，重新整理並嘗試最新版本瀏覽器。若同學也遇到相同問題，可能是服務暫時中斷。

### 公告不見了
先清除搜尋與分類條件，再重新登入更新列表。仍然沒有時，請向班級管理員確認公告狀態；不要憑摘要記憶推測內容。

### 日期或時間與同學不同
時間以裝置時區顯示。請確認裝置日期、時間及時區設定正確。

### 沒有網路能否看公告
目前不支援離線使用。請恢復連線後再試。

### 手機顯示太小
可使用瀏覽器縮放或系統文字大小設定。手機版會自動使用單欄卡片，分類列可左右捲動。

### 如何求助
使用 repository 的 Issues「使用請教」或「問題回報」，描述發生時間、裝置、瀏覽器及操作步驟。公開內容不要包含帳密、完整姓名、學號、班級名冊或未遮蔽個資的截圖。若無法存取私人 repository，直接聯絡管理員。

## 登入後要求更換密碼

若看到「請更換密碼」，輸入目前密碼、新密碼與確認新密碼，兩次新密碼需相同並與目前密碼不同。完成後才會進入公告首頁。若帳戶已停用，請聯絡教師或管理員。帳號被編輯後可能需要重新登入。
# v0.25.0 學生端重點

- 「全站搜尋」可搜尋自己有權限閱讀的公告、作業與成績。
- 作業若要求提交連結或文字，可在作業項目按「提交作業」完成；原有勾選功能仍保留。
- 成績簿會依教師設定的滿分與權重計算科目摘要，未公開的成績不會顯示。
- 「更多功能 → 聊天安全」可封鎖或解除封鎖其他學生。
- 「設定 → 帳號管理」可查看登入裝置並登出不認識的工作階段；「通知」可選即時、每日或每週電子郵件摘要。
