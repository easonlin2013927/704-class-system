# 教師使用手冊

## 作業與學生紀錄（v0.14.0）

首頁「新增」可登錄作業、缺交項目及個別評語。作業可依科目與日期一次新增多項，並指定全班或個別學生；學生有各自的勾選紀錄。缺交與評語只對指定學生顯示。完整步驟見[班級管理手冊](Classroom-Management.md)。

## 公告編輯工作室（v0.11.0）

頁首統一顯示「班級公告」。從首頁「新增 → 公告」進入部落格式寫作頁，左側輸入標題與富文字內容，右側調整分類、對象、置頂及評論開關。手機會改為單欄。

「閱讀預覽」顯示目前文章的閱讀樣式，切回「撰寫」繼續編輯。「專注寫作」暫時收起側欄，按「顯示發布設定」即可恢復。字數、閱讀時間、自動摘要及標題大綱隨內容更新；大綱由大標題、小標題產生。工具列提供復原及重做。

預覽不會發布文章。確認內容後按「發布公告」或「儲存變更」才會保存至雲端；離開前請先完成儲存。

個人資料可由「設定 → 個人化」選擇風格、上傳頭像及設定暱稱。網站標語等共用設定移至「網站設定」分類。發布公告時可勾選「開啟評論區」；既有公告僅張貼者或管理員可切換評論區。關閉會隱藏評論並停止留言，重新開啟仍會保留舊評論。評論本人、公告張貼者及管理員可刪除評論。

首頁公告區的活動倒數可建立活動名稱及時間（依目前裝置時區輸入），儲存後學生登入即可看見倒數；可編輯或刪除，活動到期後不會自動移除。公告對象已改為「學生、教師、全部人員」。

[前往教師登入](https://easonlin2013927.github.io/704-class-system/?v=0.14.1#/teacher/login)

本文件供已取得教師權限的使用者閱讀。教師帳號須由管理員建立，教師可建立學生帳號，介面切換身分不會取得資料庫寫入權限。

## 登入與權限

使用 README 的「教師登入」獨立連結，輸入教師或管理員提供的帳號與密碼。自架版本只有 accounts704 內 role 為 teacher 的帳號能發布、修改或刪除公告。學生即使直接呼叫 API，也無法寫入。

目前所有教師可共同維護公告內容。編輯既有公告時保留原發布者與發布日期；評論區開關僅供公告張貼者及管理員調整。

## 撰寫公告

1. 在公告管理首頁展開「新增」，選擇「公告」。
2. 輸入最多 80 字的明確標題。
3. 選擇分類與公告對象。
4. 在公告內容區輸入文字。
5. 視需要啟用置頂。
6. 按「發布公告」，等候成功提示並確認列表出現內容。

標題和內文為必要欄位。公告對象可選學生、教師、全部人員。學生只能看見學生及全部人員公告；教師與管理員可管理全部公告。不要以此發布特定學生的敏感資訊。

## 富文字格式

先選取文字，再按粗體、斜體或底線。清單工具可建立項目符號或編號；段落下拉選單可選一般文字、大標題、小標題或引用。

螢光筆工具可選顏色並標示選取文字。建議只標示截止日期、集合時間及關鍵動作，避免整篇使用螢光筆。

插入連結時先選取文字，輸入以 https:// 或 http:// 開頭的完整網址。發布後請實際開啟確認。貼上的格式可能因安全處理而簡化，腳本、嵌入頁面及不安全屬性會移除。

支援直接貼上截圖（Ctrl＋V），或使用工具列「＋圖片」選取 PNG、JPEG、WebP。單張原圖最多 10 MB，系統會縮放壓縮，圖片會隨公告內容保存於雲端；公告圖片總量超出容量時會提示減少圖片。選取圖片後可按刪除鍵移除。貼上 HTTP／HTTPS 網址會轉成超連結，既有公告中的純文字網址也會在閱讀時自動變成連結。

目前不支援 Word 檔上傳、一般附件、表格、字型大小自由設定或協作編輯。可將一般附件放在學校允許的平台，再加入分享連結並確認學生有閱讀權限。

## 置頂、修改與刪除

置頂公告會顯示在列表前方，多則置頂依發布日期排序；取消置頂不會刪除內容。

使用卡片的編輯按鈕或全文頁「編輯公告」修改，按「儲存變更」後才會寫入雲端。取消或關閉頁面會失去尚未儲存的內容。目前沒有草稿、自動儲存或版本復原，重要文字建議先自行留存。

刪除須確認一次，成功後才從列表移除。目前沒有回收桶。若誤刪，請管理員從事先製作的資料庫備份處理；沒有備份時不保證可復原。

## 保存原則

發布成功的資料保留於 PostgreSQL 資料庫，不依賴教師或學生的本機儲存。系統不設定公告期限、不定時清空，也不在部署時重建資料表。

資料庫專案遭刪除、服務中斷、管理員手動變更或未維護備份仍可能影響資料。請管理員定期備份並確認服務方案及帳單狀態。

## 操作失敗與疑難排解

- 發布失敗：內容保留在目前編輯頁；先複製內文，再確認網路、帳號權限與登入狀態。不要在無成功提示時假設已儲存。
- 請重新登入：登入憑證只存在記憶體，逾期或頁面重新整理後需要登入。先保存未發布文字。
- 重複點擊發布：操作完成前避免重複點擊；若出現重複公告，先確認內容後刪除多餘項目。
- 學生看不到：請學生清空篩選並重新登入。確認發布成功、不是仍停在編輯頁。
- 格式無效果：先選取文字再操作工具；換用更新的 Chrome、Edge、Firefox 或 Safari。瀏覽器對原生富文字工具支援可能略有不同。
- 多人同時修改：目前沒有衝突偵測，後寫入的內容可能覆蓋前一版本。請先協調維護時段。
- 系統尚未設定：由管理員完成雲端設定；不能使用任意示範密碼登入。
- 忘記密碼：請管理員處理，網站沒有自行重設介面。
- 需要協助：到 Issues 選「問題回報」「使用請教」或「網站建議」，不要提交密碼或學生個資。

## 建立學生帳號

上方「學生帳號」會顯示學生名單，點「建立學生」才開啟表單。帳號可為一般名稱，不需電子郵件；姓名可留空，密碼不限制長度且可留空。教師可建立與編輯學生，無法建立教師或管理員，也無法修改角色或刪除帳號。登入帳號必填且不可重複。

使用者可在「設定 → 帳號管理」新增其他收信信箱，驗證碼有效 5 分鐘。預設信箱由管理員管理。個人化桌布會套用於登入後的各個系統頁面。

教師新增公告、活動、作業、缺交紀錄、評語或成績時，系統會為對應收件人排入電子郵件。加扣分不發送即時通知；每週五台灣時間晚上 8 點，啟用中的帳號會排入班級排行榜郵件。離線聊天提醒依最近 2 分鐘的前景使用情況推估，無法直接偵測實際網路狀態。

## 編輯帳號與登入選項

在名單按「編輯」可修改登入帳號、姓名、狀態，管理員亦可更換角色。勾選「重設密碼」才會替換原密碼，未勾選時即使欄位留空也不會清空密碼。「登入時要求更換密碼」會讓使用者登入後先更換密碼，完成前不能使用一般功能；「停用帳戶」阻止登入。編輯後既有登入會失效。教師僅能編輯學生；自己不能停用自己，至少保留一位啟用中的管理員。
# v0.25.0 教師端重點

- 發布公告時可選擇立即發布、儲存草稿或指定時間排程，亦可設定下架時間。
- 進入公告內容可查看學生閱讀狀態。
- 作業簿支援補充說明、HTTPS 參考資源、勾選／連結／文字三種繳交方式及繳交名單。
- 成績簿可設定滿分、權重與學生可見性，系統會顯示加權科目摘要。
- 管理員可在帳號編輯中細分公告、作業、成績、學生紀錄、檢舉、帳號、全員通知與聊天管理權限。
