資料與隱私

隱私權政策

說明我們收集哪些資料、如何使用，以及你可以如何管理自己的資料。

生效及更新日期：2026年11月25日 · 管理者：704班級系統管理員

適用範圍收集的資料使用目的與可見範圍Google 與其他登入服務服務供應商與分享儲存與安全保存與刪除你的選擇與權利更新與聯絡

1. 適用範圍

本政策適用於 704班級系統的公開介紹頁、PWA 與系統服務。系統供獲授權的班級成員進行教學與班級協作使用，由 704班級系統管理員維運。外部網站與登入供應商另有自己的隱私權政策。

學生、教師與管理人員使用系統時，仍應遵守班級及學校適用的資料使用規範。未成年學生如不理解本政策，可請家長、監護人或教師協助。

2. 我們收集的資料

  • 帳號與個人設定：登入帳號、顯示姓名、角色、權限、密碼雜湊、暱稱、頭像、通知信箱與其驗證狀態、外觀及通知偏好。系統密碼以雜湊形式保存。
  • 教學與班級內容：公告與評論、作業及繳交狀態、成績、學生紀錄、評語、加扣分、資料繳收、留言板內容與回覆，以及英雄榜設定。
  • 聊天資料：訊息、附件及檔名、交談成員、已讀時間、在線狀態與相關操作時間。
  • 登入與技術資料：登入工作階段、瀏覽器識別資訊、最近活動時間、推播訂閱，以及維持系統運作所需的錯誤與寄信狀態。網站與網路服務供應商也可能處理 IP 位址及連線資訊。
  • 外部登入綁定：你選擇連接的供應商、該供應商的固定帳戶識別、Firebase 使用者識別、供應商提供的電子郵件（如有）與綁定時間。

3. 使用目的與可見範圍

資料用於驗證身分、控制權限、提供教學與班級功能、寄送提醒、處理帳號或安全問題，以及建立與還原備份。系統不將這些資料出售或用於投放廣告。

  • 班級留言板與回覆是全班可見的區域。英雄榜公布時會顯示入榜者的姓名、暱稱與頭像。
  • 作業、成績、紀錄與繳收資料依角色及個別權限顯示；取得額外授權的人員可能可以管理相關資料。
  • 聊天不是端對端加密的私人通訊。交談成員可閱讀訊息；管理員及獲授權的聊天管理人員可檢視紀錄與下載附件。
  • Email 或推播可能包含公告、評語、提醒、寄送者、訊息摘要與附件檔名。信箱擁有者或裝置旁的人可能看到通知內容。

4. Google 與其他登入服務

Google、GitHub 與 Microsoft 登入為選用功能，透過 Firebase Authentication 完成驗證。你必須先以系統帳密登入，再於設定明確連接帳戶。系統以供應商固定識別與 Firebase 識別對應既有帳號，不以通知信箱自動配對或建立班級帳號。

Google 驗證可能提供基本個人資料，例如電子郵件、姓名、頭像及帳戶識別；本系統的綁定記錄使用供應商、固定帳戶識別、Firebase 識別及電子郵件（如有）。本系統不要求讀取 Gmail 信件、Google 雲端硬碟或聯絡人權限，也不取得你的 Google 密碼。

Google 使用者資料僅用於上述登入、帳戶綁定與安全處理，不用於廣告、出售或與班級服務無關的用途。本系統使用及移轉從 Google API 取得的資訊，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

你可以使用系統密碼在設定中解除綁定。解除後，本系統移除該供應商連結，並撤銷由該綁定建立的登入；這不等同於刪除 Firebase 或供應商帳戶。如需一併處理 Firebase 驗證記錄，請聯絡管理員。亦可前往 Google 帳戶的第三方連結管理撤銷相關存取。

5. 服務供應商與資料分享

為提供功能，必要資料可能經由下列服務處理，而非只存在你的裝置：

  • Google／Firebase Authentication：處理你選擇的外部登入驗證；Google、GitHub 或 Microsoft 會接收與其登入流程相關的請求。
  • GitHub Pages：提供公開網頁與靜態資源，可能處理瀏覽請求與技術紀錄。班級資料不因網站原始碼公開而公開。
  • Cloudflare 與管理員維運的伺服器：傳遞 API 請求，處理登入、資料庫與上傳檔案。
  • 郵件與裝置推播服務：依設定處理收件地址、通知內容、推播訂閱及投遞資訊。

服務供應商可能在不同地區處理資料，並適用其服務條款與隱私權政策。除提供功能所需、你另行同意，或依法處理外，管理員不任意對外揭露班級資料。

6. 儲存、Cookie 與安全

帳號與班級資料主要存放在管理員維運的 API、資料庫與上傳空間。PWA 會快取程式與靜態資源；登入工作階段可能使用 Cookie。勾選「記住我」時，登入可持續至登出、撤銷或帳號狀態變更，請勿在共用電腦上保留登入。

系統使用 HTTPS、密碼雜湊、工作階段與功能權限等方式限制存取；這些措施不代表資料絕不會因錯誤、裝置遭入侵或不當操作而外洩。請不要上傳與班級使用無關的敏感資料。

7. 保存期間與刪除

帳號、教學、聊天文字與操作紀錄，依班級運作、帳號管理與安全處理的需要保存。目前沒有適用所有資料的統一自動刪除期限；如希望停止使用或刪除資料，請向管理員提出申請。

聊天附件目前在上傳約三天後到期，過期或已收回訊息的附件不再提供正常下載，實際檔案由清理作業處理。這項期限不代表聊天文字、其他上傳圖片或備份也會在三天後刪除。

管理員可以建立及下載資料庫備份。備份由管理員管理，目前沒有固定的自動到期期限；線上資料被刪除，不代表既有備份或已寄出的通知同步消失。處理刪除申請時，管理員需一併確認保留的備份及可控制的副本，說明仍需保留的內容與原因。

8. 你的選擇與資料請求

  • 可在設定中管理暱稱、頭像、通知信箱、通知偏好與外部登入綁定。全站通知開關會優先於個人設定。
  • 可向管理員請求查詢、更正、提供或刪除你的資料，或要求停止使用帳號；管理員會先確認身分、權限與需保留的教學或安全紀錄，再回覆處理方式。
  • 不使用 Google 等外部登入時，仍可用系統帳密登入。關閉選用通知不等於刪除原有班級內容。
  • 部分內容涉及其他成員或教學紀錄，可能無法直接刪除整份共同紀錄；管理員會說明可處理的範圍。

9. 更新與聯絡

政策調整會更新本頁日期；若資料用途有重大變更，會透過系統公告或其他適當方式說明。新增登入供應商或資料用途前，應更新相應說明。
